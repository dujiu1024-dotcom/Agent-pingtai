SYSTEM OVERVIEW　/　2026
01 / PLATFORM POSITIONING

它不是一个聊天机器人，
而是一套 AI 工作操作系统

大白话理解：像给企业配了一支数字员工团队，以及管理这支团队的工作台、流程制度和安全门禁。

🧠

AI 专家团队

研究、分析、执行、审核等不同 Agent 分工协作，围绕同一个目标共同完成任务。

🗂️

统一工作台账

项目、任务、运行、资料、证据和决策有明确归属，过程和成果可以持续沉淀。

🛡️

带护栏的自动化

低风险工作可自动处理；对外发送、资金和权限等高风险动作必须审批或由人执行。

一句话：平台负责让 AI 团队“有组织地工作”，行业 Agent 负责让它“懂具体业务”。

03 / HOW IT WORKS

一个任务从提出到交付，经历什么？

平台把原本散落在聊天、人工操作和多个系统里的工作，组织成一条可追踪的执行链路。

01 接收目标

用户提出需求、上传资料或创建任务。

02 拆解工作

编排流程，把子任务分配给合适的 Agent。

03 协同分析

查知识、共享证据、交叉检查和讨论冲突。

04 受控执行

调用授权工具；必要时暂停等待人工审批。

05 交付沉淀

输出结果，保留记录、证据和可追溯资产。

不是让多个模型自由聊天，而是通过任务、共享黑板和明确工作流协作。每一步都有状态和责任边界。

05 / SECURITY & GOVERNANCE

让 AI 有能力，也有边界

平台不是给 Agent 无限权限，而是把权限放在服务端，把风险规则放在工具网关。

L0 · READ

只读操作

读取已授权资料、检索和内部分析，可按策略自动执行。

L1 · REVERSIBLE

内部可逆写入

创建草稿、更新任务草案、提交黑板提案，自动执行并留痕。

L2 · APPROVAL

外部或不可逆动作

发消息、发布内容、提交外部系统等，必须人工审批。

L3 · HUMAN CONTROL

资金、权限与安全动作

付款、签约、密钥管理和授权变更由有权限的人直接执行。

审批会绑定具体动作和参数摘要。参数发生变化，原审批失效；模型不能自行声明风险级别或伪造权限。
