# Migration dry-run diff report

`scripts/migration_diff.py` compares read-only JSONL exports from the legacy source and PostgreSQL target. It does not write to either system and is safe to use before switching the authoritative writer.

```bash
python scripts/migration_diff.py --source source.jsonl --target target.jsonl --key-field id
```

Exit codes: 0 = exact match, 1 = differences found, 2 = invalid input or unreadable files. The JSON report includes missing rows on either side, changed payloads, counts, and deterministic snapshot checksums. Use the same normalized export contract on both sides; do not treat a dry-run diff as permission to switch production writes.

Actual old-schema export, data migration, rollback execution, and production deletion adapters remain environment-specific and are not run here. Those steps are marked **「待用户真机验证」**.
