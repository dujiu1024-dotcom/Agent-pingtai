# 平台工作台 Blackboard 交互

工作台在现有独立 `platform-ui` 页面增加协作黑板视图：

- 选择任务、运行、项目或租户范围并输入范围 ID。
- 通过统一平台 API 查询条目。
- 展示条目类型、版本、作者、内容和证据引用。
- 对单条目读取追加式版本历史。
- 所有数据仍由后端认证主体、租户绑定仓储和 scope 授权控制；前端不传入 actor 或 tenant 身份。
- 当能力发现接口未声明 `blackboard=true` 时，页面不发起黑板请求；不会使用模拟数据或未实现的占位接口。

本次仅补齐 Blackboard 可视化入口与版本追溯。Agent 注册、任务执行、审批、模型/工具目录等视图继续依据服务端能力声明启用；尚未挂载的服务明确显示未接入。
