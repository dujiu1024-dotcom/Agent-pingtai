# 记忆版本历史与访问边界

平台记忆采用追加式版本记录。每次候选创建、确认、纠正、状态变更和删除都会产生新的版本；历史用于解释当前记忆的来源与治理过程，不作为可直接检索的活动记忆。

## 查询契约

`GET /api/platform/v1/memories/{memory_id}/history`

返回该记忆的版本序列，包含版本号、内容、来源引用、置信度、状态、确认人和记录时间。

## 授权

- 查询范围始终由认证上下文中的 tenant_id 决定，不接受请求体指定租户。
- 个人记忆仅本人或拥有 `memory.manage` 的管理员可查看历史。
- 项目/Agent 记忆仅对应范围管理者或管理员可查看。
- 不存在的记忆返回 404；无权查看返回 403。
- PostgreSQL 从 `platform_memory_versions` 读取追加式历史；内存仓储保留同等版本快照以支持单元测试。

## 验收限制

本次增加版本历史读取能力及授权测试。CI 未实际运行前不将测试记为通过；真机/部署验证按要求跳过，待用户真机验证。
