## 4. 已显露的证据缺口

1. **数字员工独立资源域**：A-03、DE-01～DE-09、R-04 的独立 UI/API/Service/Repo/DB 证据没有形成闭环；不得用 Agent 或 User 资源替代 DigitalEmployee。
2. **业务产品入口缺口**：行业应用、流程挖掘、决策、多模态等目标未定位到专属页面/API 时，按未定位处理；通用模型或文件模块不能替代产品能力。
