# 平台管理工作台实现说明（Issue #14）

新增独立入口：`platform-ui/index.html`，不修改旧 `console.html` / `gui.py`。

页面提供工作台、Agent 管理、任务/运行、人工审批、知识库、记忆、模型模板、工具与 Skills 导航；桌面与窄屏采用响应式布局。前端只调用 `/api/platform/v1` JSON API，不在浏览器执行业务授权或直接访问数据库。

## API 契约
- `GET/POST /agents`
- `GET/POST /tasks`；`GET /runs`
- `GET /approvals?status=pending`；`POST /approvals/{id}/approve|reject`
- `GET/POST /knowledge/documents`
- `GET /memories`
- `GET /model-templates`；`GET /tools`

## 当前集成状态
知识库与记忆接口已在 `agent_platform/api/knowledge_memory.py` 提供 FastAPI Router，并由宿主注入认证后的 Principal Resolver；需在应用启动时挂载该 Router。Agent/模型/工具/Skills 注册、Task/Run 与审批接口仍需与 #6—#9 的控制面服务对接；这些依赖 Issue 尚未全部验收。因此当前 UI 已能对接知识库/记忆接口，但尚不是完整用户可操作闭环，不能关闭 #14。旧 UI 保持原样可用。
