## Harness 统一观测组合

`compose_quota_enforced_harness` 支持显式注入 Observer、Metrics 和成本估算器。在保留既有配额强制层的前提下，按“Provider Harness → QuotaEnforcedHarnessAdapter → ObservedHarnessAdapter”顺序组合，确保观测覆盖最终平台执行边界（包括配额拒绝/结算异常），而不是要求每个 Provider 单独实现 Trace。

- 不传入观测依赖时维持原有返回类型与行为，兼容既有调用方。
- 显式传入 observer/metrics、启用内容采集或成本估算时，自动在配额层外包装统一观测适配器。
- 默认不采集 Prompt/输出正文；内容采集仍需显式启用并执行脱敏和长度限制。
- 生产启动代码应复用同一 MetricsRecorder 实例，并传入 `PrometheusClientMetricsRecorder`；Langfuse 使用自托管 SDK v3 Sink。
