# 知识库连接器增量删除契约

## 变更事件

连接器的 `ConnectorPage` 同时承载新增/更新文档和源端删除墓碑：

- `items`：新增或更新的文档内容。
- `deleted_document_ids`：源端已删除的文档 ID。
- `next_cursor`：本页事件游标；只有本页新增/更新和删除全部成功后才持久化。
- `has_more`：是否仍有下一页。

连接器应将新增/更新与删除事件放在同一增量游标序列中，避免游标越过尚未应用的删除事件。

## 所有权与隔离

知识服务在接入文档时写入保留元数据字段 `_knowledge_connector_id`。若文档已标记为其他连接器所有，拒绝覆盖。删除墓碑只允许删除同一租户内、且该字段与当前连接器 ID 一致的文档。

- 跨租户文档在进入解析前拒绝。
- 其他连接器的文档不能被当前连接器删除。
- 已不存在的文档视为已应用墓碑，重复事件幂等。
- 删除复用知识仓储的事务删除能力，清除所有版本的分块、向量和 ACL 派生数据。
- 失败时不推进当前页游标，允许重试。

## 观测结果

`sync_connector` 返回 `documents` 和 `deleted_documents` 两个计数，分别表示本轮接入/更新与实际删除数量。该计数不代表源端事件总数（重复删除墓碑不会重复计数）。

## 安全边界

连接器凭据仍由外部密钥存储管理；撤销连接器授权由连接器实现 `revoke`。此契约只处理已授权同步过程中收到的内容变更和删除事件，不把连接器授权撤销等同于自动删除全部历史数据。授权撤销后的保留/清除策略仍需由平台连接器管理流程明确触发。
