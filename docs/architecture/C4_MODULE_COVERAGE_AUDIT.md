4. **记忆与知识有独立服务层**：Memory 服务区分 scope/status；Knowledge 服务声明 ACL-first hybrid retrieval。需要检查每个 connector、向量检索后过滤与删除传播路径。
5. **工具执行有服务端授权设计**：Gateway 的文档说明 actor/registry 来自可信服务端输入，且调用审批 verifier；仍需核验每类工具执行是否都经过该路径、网络/文件系统沙箱和审计是否强制。
6. **前端具备独立工程脚本**：package scripts 声明 build、lint、typecheck、Vitest、Playwright；本轮未运行这些命令，不能标记通过。
7. **生产 Compose 有安全默认项**：API 容器配置 read_only、非 root 用户、secret file；本轮未验证镜像构建、离线启动、公共控制平面断网自治或恢复演练。
8. **文档漂移风险**：当前根目录 `README.md` 仍描述旧式单文件/SQLite/FDE 工具链，而仓库同时存在 `agent_platform/`、`frontend/` 与 Postgres 生产部署代码；需在总体差距报告中明确区分主产品入口与历史资产。
