## 1. 问题与证据

| # | 问题 | 证据 |
|---|---|---|
| 1 | 平台只能“写”，不能“做” | 现有执行仅 `agency.py run` + 模型调用，产出为 Markdown，无界面操作能力 |
| 2 | 大量能力只存在于桌面 App 或网页 | 豆包、Trae、浏览器后台等，无稳定公开 API 或 API 计费 |
| 3 | 人在场才能搬运动作 | 内容、数据、配置需手工从产出复制进软件 |
| 4 | 夜间空转 | 事件总线已可夜间投递，但无“执行侧”承接 |
| 5 | 无界面操作证据 | `agent_runs` 只记调用，无截图、无动作日志 |

## 2. 目标与非目标

**目标**

1. 手机发一句话，平台在本机打开应用、完成多步操作、把结果与截图回传。
2. 支持夜间无人值守，异常可停手、可回放、次日可续。
3. 操作行为可审计：每一步有动作、有截图、有校验结论。
4. 不新增数据表，不引入 Python 第三方依赖。

**非目标**

1. 不做通用 shell，不接受任意命令拼接。
2. 不做“招聘 agent”工作流（HR 起草、人工落盘即可）。
3. 不把 OpenClaw 作为平台底座或编排器。
4. 不替代现有双闸门、预算与事件总线。

## 3. 已定决策

| 编号 | 决策 | 结论 |
|---|---|---|
| D10 | 桌面 App 执行方式 | 直接调 Peekaboo CLI，不套 OpenClaw |
| D11 | 浏览器执行方式 | 暂借 OpenClaw `browser` 命令（纯标准库缺 WebSocket） |
| D12 | OpenClaw agent 模式 | 仅探索期使用，不进业务链路 |
| D13 | 探针能力包 | 默认关闭，产物不入库，用完即弃 |
| D14 | 默认执行通道 | App 优先，API 降为可选兜底 |
| D15 | 无人值守锁屏 | 允许保持不锁屏，配合专用桌面空间 |
| D16 | 后台操作优先级 | 后台元素操作 > 前台键鼠；避免抢焦点 |
| D17 | 写操作确认 | A2 清单待定，暂按“只读自动、写操作确认、夜间仅预授权” |
| D18 | 额外模型 | 暂不拉取，按需再装；选择器必须能在缺模型时降级 |
| D19 | 策略配置 | 模型、通道、风险、夜间许可可配置；**动作原语不可配置** |

## 4. 总体架构

```
入口层    手机飞书 / 控制台 / 终端
   ↓
编排层    agency.py：任务 · 队列 · 闸门 · 预算 · 策略层（模型 / 通道 / 风险）
   ↓
Agent 层  11 角色：判断做什么；按策略选模型
   ↓
操作层    感知 / 动作 / 校验 / 会话 / 停手 / 预检
   ↓
通道层    App（默认） │ 浏览器 │ API（兜底） │ 探针（旁路）
   ↓
数据层    SQLite 21 表 + agency/state/gui + agency/outputs
```

职责边界：

| 层 | 负责 | 不负责 |
|---|---|---|
| Agent 层 | 目标拆解、内容生成、合规判断 | 坐标、控件定位、点击 |
| 操作层 | 看界面、执行动作、逐步校验 | 业务目标、预算决策 |
| 编排层 | 任务状态、闸门、队列、计量 | 窗口与元素细节 |

## 5. 组件设计

### 5.1 应用注册表

路径：`agency/apps/<app_id>.json`

```json
{
  "id": "doubao",
  "name": "豆包",
  "bundle_id": "com.bytedance.doubao",
  "launch": "open -b com.bytedance.doubao",
  "window_match": "豆包",
  "interactive": [
    {"key": "input", "role": "AXTextArea", "title": "输入"},
    {"key": "send", "role": "AXButton", "title": "发送"}
  ],
  "dialogs": ["登录", "更新", "权限申请"],
  "dangerous": ["删除", "清空", "退出登录"],
  "verified_at": "2026-11-11"
}
```

规则：

1. 只有登记在册的应用才允许操作，未登记直接拒绝。
2. `dangerous` 命中即停手，不自动确认。
3. 注册表条目必须由一次真实验证产生，不允许凭空编写。
4. 应用升级后 `verified_at` 失效，下次运行前需重新验证。

### 5.2 会话

路径：`agency/state/gui/<session_id>/`

```
state.json        # 状态机：running / waiting / stopped / done
actions.jsonl     # 每步动作、结果、耗时
steps/001.png     # 逐步截图
summary.md        # 结束后生成，进 outputs
```

`state.json` 关键字段：

| 字段 | 说明 |
|---|---|
| session | `gui-20261111-231500-a1b2` |
| task / app / goal | 关联任务、目标应用、目标描述 |
| status | running / waiting / stopped / done |
| step / max_steps | 当前步与上限（默认 30） |
| stop_reason | 未知弹窗 / 验证码 / 支付页 / 超步数 / 校验失败 / 权限缺失 |
| artifacts | 截图与产出清单 |

断点续跑：`status=stopped` 且 `stop_reason` 可解除时，允许从 `step` 继续，不重放已完成动作。

### 5.3 感知

| 方式 | 命令 | 说明 |
|---|---|---|
| 元素树 | `peekaboo see --app <app> --json` | 主通道，输出可交互元素及 AX 路径 |
| 窗口截图 | `peekaboo see --app <app> --no-elements --path <png>` | 按窗口抓取，不要求前台 |
| 兜底 | 全屏截图 + 视觉定位 | 仅探针或元素树为空时使用 |

约束：窗口不得最小化；建议固定在同一桌面空间。元素树为空时判定为“自绘界面”，转探针。

实现备注（v4.5.0 实测）：`peekaboo image` 在 v4 已移除，窗口截图改由 `see --no-elements` 承担；锁屏判定读 `ioreg -n Root -d1 -a` 的 `IOConsoleLocked`，睡眠判定读 `pmset -g assertions` 的 `PreventUserIdleSystemSleep`。

### 5.4 动作

白名单动作，全部通过子进程执行，不接受自由文本拼装：

| 动作 | 参数 | 说明 |
|---|---|---|
| `click` | selector | 优先 AX 元素，坐标仅兜底 |
| `set` | selector, value | 直接设置输入框值，不抢焦点 |
| `type` | text | 前台输入，仅在 `set` 不可用时使用 |
| `key` | combo | 快捷键，如 `cmd+enter` |
| `scroll` | selector / delta | 滚动容器 |
| `wait` | condition, timeout | 等待元素或文本出现 |
| `assert` | condition | 断言，失败即停 |
| `screenshot` | path | 记录证据 |
| `launch` / `focus` | app_id | 启动与切换窗口 |

选择器优先级：`ax_id` > `role + title` > `role + index` > `坐标`。使用坐标必须记录原因。

### 5.5 校验

| 层级 | 方式 | 用途 |
|---|---|---|
| 规则 | 窗口标题、元素存在、文本包含 | 每步默认执行，零成本 |
| 小模型（可选） | Strands Decider 2B / 规则分类 | 弹窗类型、成功/失败判断 |
| 人工 | 截图 + 确认 | A2 动作与夜间异常 |

连续两次校验失败即停手，不重试第三次。

### 5.6 停手规则

| 触发 | 处理 |
|---|---|
| 未知弹窗 | 暂停，截图，等待人工或次日汇总 |
| 验证码 / 登录失效 | 暂停，提示重新登录 |
| 支付 / 授权 / 删除页 | 立即暂停，禁止自动确认 |
| 超过 `max_steps` | 停止，标记未达成 |
| 单步超时（默认 30s） | 重试一次，仍失败则停 |
| 整会话超时（默认 10min） | 停止 |
| 权限缺失 | 开跑前阻断，不进入执行 |

### 5.7 权限预检

开跑前四项检查，任一不通过直接失败并给出操作指引：

| 检查 | 方式 |
|---|---|
| 辅助功能 | Peekaboo 自检 / AX 探测调用 |
| 屏幕录制 | 截一张图，判断是否为黑屏 |
| 是否锁屏 | 会话状态读取 |
| 是否将睡眠 | `pmset -g` 断言 |

### 5.8 夜间策略与预授权

- 时间窗：`23:00–08:00`，存 `config_kv` 键 `policy.gui.night.window`。
- 预授权清单：`policy.gui.night.allow`，JSON 数组，逐条列出“应用 + 动作 + 参数范围”。
- 清单外写操作：不入队执行，转为待办，次日汇总。
- 夜间禁止：支付、删除、授权登录、对外发布/发送、安装。
- 结束回执：一条汇总消息（成功/失败/停手原因/截图数量）。

### 5.9 通道后端

| 后端 | 调用 | 适用 | 特点 |
|---|---|---|---|
| App | Peekaboo CLI | 原生应用 | 后台元素操作优先 |
| 浏览器 | OpenClaw `browser` | 网页、后台标签 | 不抢焦点，可无头 |
| API | 现有 HTTP 客户端 | 有公开接口的能力 | 稳定、计费 |
| 探针 | OpenClaw agent | 未知应用探索 | 默认关闭，旁路 |

后端可替换：上层只依赖 `observe / act / assert` 三个接口。

实现备注（2026-11-11，OpenClaw 2026.10.7 实测）：

- gateway 需本地起 `openclaw gateway run --auth token --token <token>`，适配器从 `OPENCLAW_TOKEN` / `OPENCLAW_PORT` 读取，缺 token 直接报错，不静默降级；gateway 不常驻。
- 浏览器托管实例跑 `--headless=new`，不建可见窗口；实测一次完整填表前后前台应用不变。
- ref 只在下次 `snapshot` 前有效，动作前必须重新快照；`click` 触发导航时常误报 `Unknown ref`，适配器按 URL 变化判定成功。
- 命令与解析结果逐步写 `actions.jsonl`，`--token` 值脱敏为 `***`；截图从 OpenClaw 媒体目录回收进会话 `steps/`，产物不出会话目录。
- 会话 `kind=browser`，与 App 会话同库不同类，`agency.py browser list/show` 只看浏览器会话。

### 5.10 OpenClaw 探针能力包

| 项 | 约定 |
|---|---|
| 名称 | `openclaw_probe` |
| 启用 | 显式 `--probe` 或白名单任务，默认关闭 |
| 输入 | 目标 App + 一句话目标 + 步数上限 |
| 输出 | 能否自动化、关键元素、卡点、前后截图 |
| 数据 | 仅 `agency/state/gui/probe/`，不写库 |
| 审计 | 命令、退出码、耗时、截图 |
| 退出 | 结论固化进应用注册表后，该场景改走直调 |

实现备注（2026-11-11）：

- 入口只有 `gui probe --app <id> --goal ...` 与 `gui run --probe`，其余路径不触发探针。
- 产物固定 `agency/state/gui/probe/<probe>/`：`before.png`、`after.png`、`result.json`、`report.md`；不建 gui 会话、不写库。
- OpenClaw agent 需 gateway 凭据；当前未配置时把原始错误写进报告，并用元素树规则给出结论（可直调 / 走浏览器 / 不支持），不静默降级。
- `gui probe-promote <probe>` 才生成 `agency/apps/<id>.json` 草稿，`verified_at` 留空；已登记应用拒绝重复建档。

### 5.11 本地模型

调用方式：直连 Ollama `http://127.0.0.1:11434`，用 `urllib` 发 JSON，不引入 SDK。远程模型仍走现有客户端，两者在上层是同一个 `chat()` 接口。

| 用途 | 模型 | 状态 | 频率 | 超时 | 失败降级 |
|---|---|---|---|---|---|
| 意图路由 | `bge-m3` 召回 + `qwen3:1.7b` 判别 | 已装 | 每任务 1 次 | 5s | 规则匹配 |
| 槽位抽取 | `qwen3:1.7b`（`format=json`） | 已装 | 每任务 1 次 | 8s | 正则 |
| 每步校验 | `strands-decider:2b` | 待拉取 | 每步 | 3s | `qwen3:1.7b` → 规则 |
| 规划兜底 | `qwen3:8b` | 待拉取 | 长任务 | 60s | 远程模型 |
| 敏感内容 | 专用本地模型 | 待选型 | 按需 | 60s | 阻断，不转远程 |

实测本机现状（2026-11-11）：仅有 `bge-m3`、`qwen3:1.7b`；`qwen3:0.6b`、`qwen3:8b`、`strands-decider:2b` 均未安装，**暂不拉取，按需再装**。现有 `qwen3.5-9b-abliterated` 与命理微调模型不用于业务判断。

规则：

1. 开跑前 `GET /api/tags` 健康检查，缺模型直接报错，不静默降级到错误模型。
2. Ollama 单实例串行调用，夜间多任务排队，避免抢显存。
3. 本地模型只做判断与兜底，内容质量交给远程模型或豆包。
4. 客户资料等敏感内容默认本地处理，转发远程必须先脱敏。
5. 不把本地视觉模型作为操作主路径，仅在探针中使用。

计量：键 `llm.local.<日期>` 记调用次数与耗时，不折算 token。

实现备注（2026-11-11）：`llm_local.py` 直连 `/api/tags`、`/api/chat`、`/api/embed`；当前策略 route/extract/judge 首选 `qwen3:1.7b` → `rules`，plan 走 `remote:doubao` → `qwen3:1.7b` → `rules`，embed 用 `bge-m3`。未装模型时 `chat()` 报错并列出已装清单。

### 5.12 模型选择器

作用：把“用哪个模型”从代码里抽出来，变成一张可查、可改、可解释的路由表。没有它，每个调用点都会硬编码模型名。

| 输入 | 说明 |
|---|---|
| 用途 | `route` / `extract` / `judge` / `plan` / `generate` |
| 敏感级别 | `normal` / `confidential`，机密内容强制本地 |
| 时延预算 | 交互 <2s，后台 <60s |
| 成本上限 | 单任务或单日额度 |
| 健康状态 | 模型是否已装、Ollama 是否可达 |

选择顺序：

1. 显式配置 `llm.route.<用途>`（`config_kv`）优先。
2. 机密内容 → 本地。
3. 交互型短任务 → 本地小模型。
4. 质量优先 → 远程模型或豆包。
5. 首选不可用 → 按 5.11 的降级链继续。

输出：模型 ID、参数、降级链、选择理由。

可观测：`agency.py model list` 打印路由表与每个模型的可用状态；每次调用把“选择理由”写入本轮摘要，便于复盘。

约束：不建表；路由表存 `config_kv`，缺省值写在代码常量；选择器不参与业务判断。

### 5.13 策略层（可配置）

原则：**策略可配置，动作不可配置。**

| 维度 | 可配置 | 说明 |
|---|---|---|
| 模型路由 | 是 | 用途 → 模型 + 降级链 |
| 执行通道 | 是 | 应用 → App / 浏览器 / API |
| 风险等级 | 是 | 动作 → A1 / A2 / A3，决定是否确认 |
| 夜间许可 | 是 | 时间窗 + 白名单 |
| 动作原语 | **否** | `click` / `set` / `type` 等是代码枚举，配置无法新增 |

配置文件：`agency/policies/gui.json`，进 git 走评审；运行时状态仍写 `config_kv`。

```json
{
  "version": 1,
  "models": {
    "route":    {"primary": "qwen3:1.7b", "fallback": ["rules"]},
    "judge":    {"primary": "qwen3:1.7b", "fallback": ["rules"]},
    "generate": {"primary": "remote:doubao", "fallback": ["qwen3:1.7b"]}
  },
  "apps": {
    "doubao": {"backend": "browser", "verified_at": ""}
  },
  "risk": {"observe": "A0", "click": "A1", "set": "A1", "launch": "A2", "focus": "A2"},
  "night": {"window": "23:00-08:00", "allow": []}
}
```

优先级：任务级 > 应用级 > 全局默认。

加载即校验：未知键、未登记动作、未安装模型一律拒绝启动，避免配置写错却静默生效。

实现备注（2026-11-11）：

- 实际策略文件 `agency/policies/gui.json` 只列白名单内动作；`send` / `delete` 等未登记动作直接拒绝加载。
- 模型标识三种形式：本地 `name`、远程 `remote:<名>`、规则 `rules`；`llm_local.chat()` 缺模型直接报错，不替换模型；选择器只按配置里写明的链降级。
- `agency.py policy check/show/explain`：`explain` 输出通道、风险、夜间窗口/白名单的生效值与来源（`config_kv` > `policy.*` > 默认）。
- `agency.py model list/select/chat/embed`：`list` 在 Ollama 停止时仍可打印路由与“不可达”；`select` 返回链路与理由；`chat` 走本地并计量 `llm.local.<日期>`。
- 每次 `gui run` / `browser run` 收尾把策略 `version + sha256` 写入会话 `state.json` 的 `policy` 字段，便于复盘。

可解释：`python3 agency.py policy explain --app doubao --action click` 输出生效值及其来源（任务 / 应用 / 默认）。

审计：会话 `state.json` 记录策略版本与哈希，事后可复现当时的决策。

## 6. 数据、事件与计量

**不新增表。** 复用与新增如下：

| 类别 | 用法 |
|---|---|
| `tasks` | 操作类任务仍走原有字段，`kind` 不变 |
| `agent_runs` | 记录发起角色与调用摘要 |
| `events` | 新增 `tool_called`、`tool_failed` 两类枚举（仅枚举，不改表） |
| `config_kv` | 存策略、预授权、每日步数消耗、最近会话摘要 |
| `agency/state/gui` | 会话状态与截图 |
| `agency/outputs` | 结束后的 `summary.md` |

计量：按“操作步数”累计，键 `gui.spend.<日期>`，与 `sync.spend.*` 并列；不折算 token。本地模型调用另记 `llm.local.<日期>`，只记次数与耗时。

## 7. 接口

### 7.1 CLI

```bash
python3 agency.py gui preflight
python3 agency.py gui observe --app doubao
python3 agency.py gui run --task T-00xx --app doubao --goal "把这段文案输入并发送" [--probe]
python3 agency.py gui list
python3 agency.py gui show <session_id>
python3 agency.py model list
python3 agency.py policy explain --app doubao --action send
```

### 7.2 控制台

## 9. 验收标准

| # | 标准 | 判定 |
|---|---|---|
| 1 | 只读验证 | 目标应用元素树 ≥10 个可交互元素，截图非黑屏 |
| 2 | 动作验证 | 白名单应用完成“输入 + 提交”并到达目标状态，逐步截图 ≥3 张 |
| 3 | 停手验证 | 人为触发未知弹窗，10s 内暂停且 `stop_reason` 正确 |
| 4 | 权限验证 | 撤销屏幕录制后开跑，直接阻断并给出指引 |
| 5 | 夜间验证 | 预授权外写操作不入队，次日汇总含待办 |
| 6 | 探针验证 | 默认关闭；开启后产物仅落 probe 目录，不写库 |
| 7 | 回归验证 | `doctor` 全绿、`check_consistency` 全绿、新增测试全部通过 |
| 8 | 本地模型验证 | 停掉 Ollama 后任务仍可执行，仅降级为规则判断 |
| 9 | 策略验证 | 改 `gui.json` 的风险等级即生效；写入未登记动作时启动被拒绝 |

## 10. 风险与回滚

| 风险 | 影响 | 应对 |
|---|---|---|
| 应用自绘界面无元素树 | 无法定位 | 转探针；探针也失败则登记为“不支持” |
| 应用升级导致选择器失效 | 动作失败 | `verified_at` 失效 + 停手 + 重新验证 |
| 系统升级导致权限重置 | 全量不可用 | 预检前置阻断，输出授权指引 |
| 熄屏后渲染暂停 | 截图黑屏 | 保持显示器常亮，或夜间改走浏览器 |
| 夜间误操作 | 数据或对外影响 | 白名单 + 预授权 + 危险动作清单 |
| OpenClaw 版本漂移 | 浏览器/探针失效 | 适配器隔离，仅影响旁路 |

回滚：删除 `agency/apps/` 与 `agency/state/gui/`，移除两个事件枚举，CLI 入口下线，其余系统不受影响。

5. 新增数据表。
