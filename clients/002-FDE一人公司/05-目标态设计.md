## 2. 提醒规则（本版修正）

| 项 | 规则 |
|---|---|
| 工作时段 | 09:00–23:00 |
| 提醒方式 | 事件驱动，不定时。任务创建、临期、逾期、阻塞、里程碑达成，任一发生即提醒 |
| 时段内 | 随时可提醒，不设固定早会 |
| 时段外 | 23:00–09:00 静默，提醒入队，次日 09:00 合并推送 |
| 例外 | 生产事故、客户当天截止、资金类事项，可越窗即时提醒 |
| 频率上限 | 同一任务每天最多 3 次，超 3 天未处理升级给幕僚长 |

教练同理：不是固定早上给题，而是任务进入"首次做某类事"或"卡住"时触发。

## 3. 系统由六部分组成

| 模块 | 作用 | 对应 Agent |
|---|---|---|
| 状态库 | 项目、任务、事件、事实、运行记录，唯一事实源 | 全部 |
| 事件引擎 | 扫描到期/临期/逾期/阻塞，生成提醒 | 秘书 |
| Agent 运行时 | 加载角色、组装提示词、调模型、存产出 | 全部 |
| 审计引擎 | 检查事实来源、日期、假设标注 | 审计 |
| 飞书同步 | 单向推送 + 冲突检测 | 全部 |
| 命令行 | 你唯一的操作入口 | 你 |

## 4. 一天怎么用（按事件，不按钟点）

```
09:00  系统补发夜间积压提醒（若有）
任意时刻
  ├─ 有新任务        → 秘书校验五要素，缺则退回
  ├─ 任务临期        → 秘书提醒，附完成标准与证据要求
  ├─ 任务逾期        → 秘书提醒 + 升级标记
  ├─ 首次做某类交付  → 教练给指南 + 考题
  ├─ 交付卡住        → 教练给排查路径
  ├─ 里程碑达成      → 幕僚长出简报，规划师校排期
  └─ 客户确认/变更   → 产品经理出影响评估
23:00  停止推送，未完成事项入队
```

没有"早会"，也没有"日报时间"。你什么时候干活，事件就什么时候找你。

## 5. 一个项目怎么走

```
线索 → 商机侦察建档
接单 → 产品经理：需求采集 → 诊断 → 方案三选一 → 确认单
排期 → 规划师：WBS → 关键路径 → 任务入台账
执行 → 秘书排期提醒 → 教练伴随 → 你执行
验收 → 教练验收 → 秘书凭证据关闭
收尾 → 内容沉淀案例 → 审计抽查 → 飞书归档
```

闸门：无确认单不写代码；无证据不关闭任务。

## 6. 迁移交付什么

给别人时，一个压缩包：

| 内容 | 说明 |
|---|---|
| `agency/` 代码 | 不含任何密钥 |
| `agents/` 角色定义 | 9 个角色 |
| `templates/` 模板 | 诊断、方案、报价、WBS、验收 |
| `state/` 示例数据 | 一个演示项目 |
| `.env.example` | 变量清单，不含真实值 |
| `README.md` | 三步安装：装依赖、填密钥、doctor |

迁移验收：解压到新目录 → `doctor` 通过 → `check` 能报出任务 → `run` 能出草稿。

## 7. 彩排脚本（11-16）

1. 外援拿到压缩包，不看你的说明，自己装。
2. 装完跑 `doctor`，失败就记录卡点。
3. 建一个演示任务，跑一次秘书提醒 + 教练出题。
4. 全程录屏，不做剪辑。
5. 结束填《迁移卡点表》，卡点超过 3 个则不上线。
