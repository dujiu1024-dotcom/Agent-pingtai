## 7. P0 实际技术栈（现状核实，2026-11-11）

上表是「不引入什么」，本节是「实际用什么」。以运行环境实测为准，不写计划中的。

### 7.1 运行环境

| 项 | 实际值 | 说明 |
|---|---|---|
| 操作系统 | macOS | 单人开发机 |
| Python | 3.14.6 | 仅标准库，无 pip 依赖 |
| 状态存储 | SQLite `agency/state/agency.db`（13 张表，WAL，schema v4） | 单一事实源；旧 JSON 已迁移，仅作备份 |
| 入口 | `agency.py` + `db.py` / `memory.py` / `vectors.py` | CLI：init / doctor / migrate-json / task / gate / check / brief / wbs / run / memory / vector / project / export / import |
| 版本控制 | 本地 git + Gitee 私有仓库 | `main` 已推送；`origin = git@gitee.com:ghost-eye/FDE-OPC.git`，SSH 公钥免密，无令牌落盘 |

### 7.2 模型

| 项 | 值 |
|---|---|
| 通道 | 商汤 SenseNova，OpenAI 兼容 `/chat/completions` |
| 接入点 | `https://token.sensenova.cn/v1`（`.env` 的 `OPENAI_BASE_URL`） |
| 默认模型 | `deepseek-v4-flash`（`.env` 的 `AGENCY_MODEL`） |
| 限流模型 | `kimi-k3`、`deepseek-flash`、`glm-5.3` |
| 未开通 | `sensenova-u1.5-lite` |
| 密钥 | 只存本地 `.env`，600 权限，不入包不上传 |
| 兜底 | `agency/config.json` 默认 `gpt-4o-mini`，仅当 `.env` 缺失时生效 |

### 7.3 嵌入与检索（P0 已接入，2026-11-11 实测）

| 项 | 方案 |
|---|---|
| 首选 | 本地 Ollama + `bge-m3`（1024 维，已索引 11 份文档 89 块） |
| 兜底 | 纯标准库 `hash-tfidf-512`，随主索引同步维护，Ollama 掉线仍可检索 |
| 接口 | `vectors.index_path / search / delete_by_source`，P1 换 Chroma/pgvector 不动上层 |

**存储定版**：SQLite 为唯一事实源（`agency/state/agency.db`，schema v4）。理由：关闭证据、事件去重、记忆槽位写入都要求原子性，JSON 的并发写与半截文件风险已在迁移前暴露；迁 SQLite 是一次性成本，后续不再为此返工。
