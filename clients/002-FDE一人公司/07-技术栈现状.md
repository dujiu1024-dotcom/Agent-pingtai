## 7. P0 实际技术栈（现状核实，2026-11-11）

上表是「不引入什么」，本节是「实际用什么」。以运行环境实测为准，不写计划中的。

### 7.1 运行环境

| 项 | 实际值 | 说明 |
|---|---|---|
| 操作系统 | macOS | 单人开发机 |
| Python | 3.14.6 | 仅标准库，无 pip 依赖 |
| 状态存储 | 纯文本 JSON（`tasks.json` / `gates.json` / `events.jsonl`） | 零依赖，可直接拷 |
| 入口 | 单文件 `agency.py` | 12 个命令：init / doctor / task / gate / check / brief / wbs / run / project / export / import |
| 版本控制 | **无 git（缺口）** | 当前目录不是 git 仓库，改动无历史、无法回滚 |

### 7.2 模型

| 项 | 值 |
|---|---|
| 通道 | 商汤 SenseNova，OpenAI 兼容 `/chat/completions` |
| 接入点 | `https://token.sensenova.cn/v1`（`.env` 的 `OPENAI_BASE_URL`） |
| 默认模型 | `deepseek-v4-flash`（`.env` 的 `AGENCY_MODEL`） |
| 限流模型 | `kimi-k3`、`deepseek-flash`、`glm-5.3` |
| 未开通 | `sensenova-u1.5-lite` |
| 密钥 | 只存本地 `.env`，600 权限，不入包不上传 |
| 兜底 | `agency/config.json` 默认 `gpt-4o-mini`，仅当 `.env` 缺失时生效 |

### 7.7 三处待处理偏差

| # | 偏差 | 影响 | 处理 |
|---|---|---|---|
| 1 | 《06 技术方案》写 SQLite，实际是 JSON | 文档与实现不一致，审计会挑 | 二选一定版，见下 |
| 2 | 无 git 版本控制 | 改坏无法回滚，迁移无版本号 | 补 `git init` + `.gitignore`（已覆盖 `.env`） |
| 3 | 嵌入未接入 | 向量记忆无数据 | 按 T-0010 在 11-14 落地 |

**存储定版建议**：当前 JSON 已承载 15 条任务、8 条主任务、68 条分项，量级远未到 JSON 的瓶颈；SQLite 的价值在事务与并发，而本项目是单人单进程。建议把《06 技术方案》改为"JSON 为主、SQLite 仅在需要事务时引入"，而不是反向改代码。
