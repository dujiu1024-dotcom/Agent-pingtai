# Agent 平台｜独立对外演示版

这是一个**纯静态、浏览器端运行**的产品演示包。它不依赖生产前端源码，也不需要部署 API、数据库、Redis、消息队列、MCP Server 或其他后端服务。

## 直接预览

最简单的方式：在浏览器中打开 `index.html`。

也可以把整个 `演示demo/` 目录放到任意静态文件服务器上，通过 `/index.html` 访问。无需执行 `npm install`，无需构建。

## 对外部署

只需上传以下目录中的静态文件：

- `index.html`：演示页面入口。
- `demo-runtime.js`：浏览器本地交互、数据保存与导出。
- `prototype-original.html`：原始交互原型备份；不影响正式演示入口。

部署方式任选其一：
1. 上传 `演示demo/` 目录到 Nginx、对象存储静态网站托管或任意静态站点平台。
2. 将该目录作为静态站点根目录，默认文档指向 `index.html`。
3. 将站点配置为 HTTPS 后即可对外分享链接。

不需要 Docker，不需要 Node.js 运行时，不需要配置环境变量，也不需要连接生产系统。

## 演示内容

- 工作台：运营驾驶舱、指令中心、运行看板。
- 3D 办公室：Agent 工位、团队分布与状态。
- 任务中心：任务列表、详情、Run Trace、审批、会话、文件产物。
- Agent 协作：Agent 运行态、知识库、记忆治理。
- Workflow：流程列表、可视化编排、Prompt 与模板。
- 成本与质量：成本分析、评测数据集、评测运行。
- 系统管理：Agent 定义、模型供应商/模板/路由、Tool/MCP、Skills、组织权限、系统设置、审计、调度、事件订阅和运维。

## 演示交互与数据

- 菜单跳转、全局页面搜索、列表搜索/筛选、详情弹窗、创建记录、Workflow 节点操作、工位查看等操作均在浏览器中执行。
- 创建的演示记录保存在当前浏览器的 `localStorage`，刷新页面后仍然保留。
- 左下角可导出演示数据 JSON，也可重置当前浏览器中的演示数据。
- 所有数据均为虚构的本地 Mock 数据，不会发送到服务器，不会写入生产数据库，也不代表真实服务运行状态。
- 对外演示时建议使用专用浏览器配置文件，并在演示前重置数据。

## 目录边界

- `index.html` 是独立演示入口。
- `demo-runtime.js` 只负责本地交互和浏览器存储。
- `prototype-original.html` 保留原始视觉原型。
- 本目录不引用 `frontend/src`，不复用生产 React 组件，不调用生产 API。

## 验收边界

此 Demo 的目标是独立对外展示产品结构、页面形态与典型操作流程，不是生产系统的逐像素副本，也不提供真实 Agent 推理、模型调用、工具执行或持久化服务端能力。页面上的业务状态和指标均为演示数据。
