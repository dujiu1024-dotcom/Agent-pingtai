# Agent 平台｜独立对外演示版

## 入口

打开 `index.html` 即可进入独立演示。页面以 `示意图/Agent 平台 (3).html` 的原始视觉原型为底稿，保留原始工作台与 3D 办公室，并在同一视觉框架中增加可操作的业务模块页面。

## 部署

将整个 `演示demo/` 目录上传到 Nginx、对象存储静态网站托管或任意静态站点平台，默认文档指向 `index.html`。也可直接在浏览器打开该文件。

- 无需 npm install 或构建。
- 无需 Node.js 运行时、Docker、API、数据库、Redis、消息队列或 MCP 服务。
- 不引用 `frontend/src`，不加载生产 React 组件，不请求生产 API。

## 演示模块

- 工作台、3D 数字办公室
- 任务指挥中心、Agent 协作中心、智能体管理
- Workflow 工作流、成本与质量中心
- 知识库与记忆治理、会话与文件资产
- Prompt Registry、模型与路由管理
- Tool / MCP 与 Skills、评测中心、审批中心
- 系统设置与组织权限、系统运维与审计

左侧导航可直接切换模块。模块页提供模拟指标、列表、搜索、状态筛选、新建记录和 JSON 导出。创建的记录仅保存在当前浏览器的 localStorage 中。

## 数据与验收边界

页面中的名称、指标、状态和列表均为虚构 Mock 数据，不代表真实服务运行状态。新建与移除操作只影响当前浏览器，不会写入生产系统。导出功能下载当前模块的 JSON 数据。

`prototype-original.html` 保留原始原型备份。当前入口是重新构建的独立演示版，不是生产系统的真实运行界面，也不提供真实 Agent 推理、模型调用或工具执行能力。

## 浏览器兼容

建议使用最新版 Chrome、Edge 或 Safari。使用静态服务器访问时体验最佳；浏览器若禁用 localStorage，页面仍可浏览，但本地数据不能持久保存。
