# Agent 平台功能演示 Demo

## 页面入口

- `index.html`：独立交互式演示入口，保留七个一级模块，并将生产路由中的主要业务页面组织为子菜单。
- `prototype-original.html`：用户提交的原始交互原型备份，完整保留，不作为功能演示入口。

## 覆盖模块

工作台（运营驾驶舱、指令中心、运行看板）、3D 办公室、任务中心（任务列表/详情、Run Trace、审批、会话、文件）、Agent 协作（Agent 运行态/详情、知识库、记忆治理）、Workflow（设计列表/设计器、Prompt）、成本与质量（成本分析、评测数据集/运行）、系统管理（Agent 定义、模型供应商/模板/路由、Tool/MCP、Skills、组织与权限、系统设置、审计、调度、事件订阅、系统运维）。

## 本地预览

直接用浏览器打开 `index.html`，不需要安装依赖或启动后端。

## 交互范围与数据边界

- 菜单切换、页面跳转、列表搜索与筛选、记录详情弹窗、创建表单、Workflow 节点操作、办公室工位查看、导出/刷新/发布等演示操作均可交互。
- 页面数据是本地 mock 数据；表单提交只显示演示反馈，不写入生产数据库，也不调用生产 API。
- 这是面向产品演示的独立 HTML，不等同于生产 React 页面逐像素复刻。生产路由中尚未接入具体业务组件的页面，在此以明确的演示页面和模拟交互呈现，不代表后端能力已真实接通。
- 原始原型备份保留在 `prototype-original.html`，可用于视觉对照和后续融合。
