# Agent Platform 演示 Demo

这是一个纯前端、可交互的产品演示页面，使用 HTML + CSS + 原生 JavaScript 实现，不依赖构建工具或第三方运行时。

## 本地预览

直接用浏览器打开 `index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080/演示demo/`。

## 演示内容

- 运行总览：Agent / 任务 / 成功率 / 成本指标、任务趋势、基础设施健康、活动流
- 任务中心：搜索、状态筛选、创建任务、模拟运行任务
- Agent 管理：Agent 卡片、能力与状态
- 工作流编排：多节点流程状态、模拟启动
- 知识与记忆：文档索引与知识集合指标
- 工具安全网关：MCP 工具、风险等级、审批策略
- 可观测与审计：Trace 指标、审计事件流、CSV 导出

## 数据说明

页面内数据均为用于产品演示的模拟数据；交互在浏览器本地完成，不调用后端、不连接生产环境，不会修改真实任务、Agent、工具或审计数据。
