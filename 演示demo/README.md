# 演示 Demo

## 复刻基准

本目录的 `index.html` 直接复用仓库中的完整交互原型：

- 基准文件：`示意图/Agent 平台 (3).html`
- 本目录页面：`演示demo/index.html`

两者以相同 HTML 内容为基准，保留原型完整菜单、页面布局、视觉样式、场景资源与原有交互，不再用简化版页面替代原型。

## 本地预览

直接使用浏览器打开 `index.html`。页面为独立 HTML，包含内嵌 CSS、JavaScript 与资源，不需要安装依赖。

## 说明

- 这是对仓库原型的完整复刻基线，不代表所有按钮均已连接生产 API。
- 原型中的演示数据与交互按原文件保留；生产 API、权限和实时数据仍以当前 `frontend/` 实现为准。
- 后续逐页对照当前生产前端，补齐原型与生产系统之间的菜单、页面和行为差异。
