# 定位卡｜AI 原生运行底座

- 版本：v0.2（渠道合作定位）
- 日期：2026-11-21

---

## 1. 一句话定位

> 我们向 **软件公司** 提供一套 **AI 原生运行底座**，他们装到客户环境、贴自己品牌、加一个行业 Agent，就是一个企业级就绪的 AI 产品；我们提供底座、升级和技术支持。

拆解：
- 客户：软件公司 / 系统集成商 / 有行业客户资源的团队。
- 卖什么：AI 原生底座授权 + 技术支持。
- 他们做什么：找客户、装平台、加行业 Agent、做交付、收解决方案的钱。
- 我们做什么：底座研发、升级、部署与迁移支持。

---

## 2. 产品公式

**AI 原生底座 ＋ 行业 Agent ＝ 客户要的解决方案**

| 行业 Agent | 形成的产品 |
|---|---|
| 调酒 Agent | AI 调酒师 |
| 客服 Agent | AI 客服 |
| 法律 Agent | AI 法律助手 |
| 数据分析 Agent | AI 数据分析师 |

- 底座通用（多租户、权限、工具安全、可观测、配额），一次开发。
- 行业 Agent 差异化，属于软件公司，按行业复制 —— 他们的护城河。

---

## 3. 目标客户画像（渠道方）

| 维度 | 描述 |
|---|---|
| 是谁 | 软件公司、系统集成商、有行业客户资源的团队 |
| 他们有 | 行业客户、行业 know-how、交付能力 |
| 他们缺 | 可跑生产的 AI 底座（多租户、权限、审计、工具安全） |
| 痛点 | 自研底座要 6–12 人月，且要持续维护；底座不是他们的差异化 |
| 我们补 | 现成的企业级底座，装上就能跑行业 Agent |
| 排除 | 只想白嫖、无行业客户、无交付能力、要求我们包办行业的 |

---

## 4. 竞争定位

| 对手 | 他们强在哪 | 我们怎么打 |
|---|---|---|
| 大模型厂商 | 模型能力、品牌 | 我们不是卖模型，是卖跑生产的运行底座 |
| 通用 Agent 框架 | 开源、灵活 | 我们是企业级就绪：多租户、审计、配额、灰度迁移，不是 demo 框架 |
| 自研 | 完全定制 | 我们省 6–12 人月，交付快、持续升级 |

一句话：**比框架更企业级，比自研更快更省，比模型厂商更懂落地。**

---

## 5. 价值主张

1. **省时间**：底座已在跑，12+ 能力域开箱即用，不用从零造轮子。
2. **省成本**：自研底座 6–12 人月，买现成的快交付、早收钱。
3. **企业级就绪**：多租户、RBAC、审计、工具安全、配额、可观测、灰度迁移。
4. **可扩展**：行业 Agent 做成 Extension，一个包复制到多个客户。
