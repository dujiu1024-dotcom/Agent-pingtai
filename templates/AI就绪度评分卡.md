# AI 就绪度评分卡（5 维 / 75 分制）

- 版本：v1.0
- 对应分项：11.6
- 配套：《客户诊断问卷》（20 题 + 5 项现场核查）
- 原则：输入相同，输出必须相同；不允许"感觉不错加两分"

---

## 1. 五个维度

| 维度 | 含义 | 来源 | 满分 |
|---|---|---|---|
| D1 业务价值与目标 | 场景是否单一、目标是否可量化、是否有 owner | Q1–Q5 | 15 |
| D2 流程标准化 | 流程是否固定、有无 SOP、量与例外是否清楚 | Q6–Q10 | 15 |
| D3 数据就绪 | 数据在哪、能否导出、质量与敏感级别 | Q11–Q15 | 15 |
| D4 AI 认知与组织 | 使用经验、预期是否合理、角色与预算 | Q16–Q20 | 15 |
| D5 技术交付与合规 | 网络账号、接口、成本、合规、兜底 | C1–C5（现场核查） | 15 |
| **合计** | — | — | **75** |

---

## 2. 打分方法

### 2.1 D1–D4：查表，不重新判断

每题 4 个选项，A/B/C/D 分别对应 0/1/2/3 分。维度分 = 该维 5 题得分之和。

| 维度 | 题号 | 维度分 |
|---|---|---|
| D1 | Q1 + Q2 + Q3 + Q4 + Q5 | 0–15 |
| D2 | Q6 + Q7 + Q8 + Q9 + Q10 | 0–15 |
| D3 | Q11 + Q12 + Q13 + Q14 + Q15 | 0–15 |
| D4 | Q16 + Q17 + Q18 + Q19 + Q20 | 0–15 |

> 客户选"不清楚"的题按 C 档（2 分）以下取，具体按问卷选项；没有对应选项时取低一档，并在备注写题号。

### 2.2 D5：现场核查打分锚点

| 项 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| C1 网络与账号 | 无法访问外部 API | 有网络，无账号 | 有账号，额度待申请 | 账号与额度可用 |
| C2 集成接口 | 无任何接口或导出 | 只能人工复制 | 有导出文件 | 有 API 或只读库 |
| C3 成本预算 | 无预算 | 预算未批 | 口头预算 | 预算已批且有上限 |
| C4 安全合规 | 数据绝不可出内网且无替代 | 需法务审批 | 可脱敏后外发 | 无敏感或已有授权 |
| C5 运维与回滚 | 不接受人工兜底 | 兜底责任不清 | 同意人工复核 | 有灰度与回滚预案 |

> 现场核查以"看到"为准：没看到账号就不给 3 分，客户口头说"有"最多给 2 分。

## 3. 判读规则

### 3.1 单维判读

| 维度分 | 判读 | 含义 |
|---|---|---|
| 11–15 | 强 | 可直接进入方案设计 |
| 6–10 | 中 | 可作为试点，但要在方案里设补偿措施 |
| 0–5 | 弱 | 这一维不补，项目大概率失败 |

### 3.2 总评

就绪度 = 合计 ÷ 75 × 100，四舍五入取整。

| 就绪度 | 等级 | 建议动作 |
|---|---|---|
| 0–29 | 不具备 | 只做诊断，不报试点；给出补基础清单 |
| 30–49 | 基础薄弱 | 先做数据／流程治理，1–3 个月后复评 |
| 50–64 | 可小范围验证 | 可做单场景小样（≤2 周），或诊断档 |
| 65–79 | 可单场景试点 | 可签试点档，设量化验收 |
| 80–100 | 可规模推广 | 可议生产化档，但先验证单场景 |

### 3.3 一票否决（分数再高也降级）

出现任一条，等级最高只能到"可小范围验证"：

1. 任一维 ≤3 分；
2. Q3 选 A（没有 owner）；
3. Q12 选 A（数据完全不能导出），且无替代数据源；
4. 预算明确为 0，且不接受分期。

> 否决必须在报告第 2 节写明原因，不能只降等级不写理由。

## 4. 计算示例（与《诊断报告示例-脱敏》一致）

| 维度 | 题号 | 选项 | 得分 |
|---|---|---|---|
| D1 | Q1 C / Q2 C / Q3 C / Q4 B / Q5 C | 2 / 2 / 2 / 1 / 2 | 9 |
| D2 | Q6 C / Q7 B / Q8 C / Q9 B / Q10 C | 2 / 1 / 2 / 1 / 2 | 8 |
| D3 | Q11 C / Q12 C / Q13 C / Q14 B / Q15 B | 2 / 2 / 2 / 1 / 1 | 8 |
| D4 | Q16 B / Q17 C / Q18 C / Q19 B / Q20 B | 1 / 2 / 2 / 1 / 1 | 7 |
| D5 | C1 / C2 / C3 / C4 / C5 | 3 / 2 / 2 / 2 / 2 | 11 |
| **合计** | — | — | **43** |

- 就绪度 = 43 ÷ 75 × 100 = 57.33 → **57%**
- 等级：**可小范围验证**（50–64）
- 一票否决：无（最低维 D4 = 7 > 3；owner 已指定；数据可导出）

## 5. 复现步骤（换人打分必须一致）

1. 取问卷原始答案，按题号抄成 20 个字母（A/B/C/D），不要凭印象。
2. 查第 2.1 节映射表，逐题转分，填入计分表。
3. 取现场核查 5 项分数，填入 D5。
4. 五个维度求和，再除以 75、乘 100、四舍五入。
5. 查第 3.2 节得等级，再查第 3.3 节确认是否触发否决。

**一致性要求**
- 两人独立打分，总分差 >2 分则复核原始记录，取复核结论；
- 复核后仍不一致，取较低分，并在报告中标"评分存在分歧"。

## 7. 版本与校准

- v1.0（2026-11-11）：首次发布，阈值未用真实样本校准，标【假设·S4】。
- 校准计划：前 3 个真实客户诊断后，回看等级与最终成单／失败结果，若偏差 ≥2 档则调整阈值并升版本。
- 变更规则：题目、权重、阈值任一变动即升小版本，旧报告分数不追溯。
