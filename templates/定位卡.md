# 定位卡（一页纸）

- 版本：v1.0（对应分项 12.6）
- 用途：3 分钟内让人知道"你是谁、帮谁、解决什么、多少钱"
- 规则：一页写完；写不进去说明还没想清楚

---

## 1. 一句话

> 我帮【谁】在【多久】内把【哪件事】从【现状】做到【结果】，收费【档位】。

**填空：**

---

## 2. 目标客户

| 项 | 内容 |
|---|---|
| 行业 |  |
| 规模 | 人 / 年营收 |
| 角色 | 谁拍板、谁使用 |
| 典型痛点 | 一句话，带数字 |
| 现在怎么做 | 人工／Excel／外包 |
| 在哪里找 | 平台／社群／线下 |
| 判断信号 | 出现什么现象说明他需要（如"每天回消息 >300 条"） |

---

## 3. 不做什么（写死，防止接错单）

1. 不做 __（行业／规模不匹配）
2. 不做 __（预算低于 __ 元）
3. 不做 __（要求零错误、全自动、一周上线）
4. 不做 __（纯咨询不给数据、不给 owner）
5. 不做 __（需要自建大模型／私有化训练）

---

## 4. 交付什么

| 档位 | 内容 | 周期 | 价格 |
|---|---|---|---|
| 诊断 | 问卷 + 访谈 + 报告 + 评分 | 5 个工作日 | ¥9,800 |
| 试点 | 单场景可用系统 + 评测 + 1 个月陪跑 | 4–6 周 | ¥39,800 起 |
| 生产化 | 多系统集成 + 权限审计 + SLA | 8–12 周 | ¥150,000 起 |

> 定价与《报价单模板》一致；不在本卡上临时打折。

---

## 5. 凭什么信

| 证据 | 内容 | 可核验方式 |
|---|---|---|
| 方法 | 5 维就绪度评分 + 30 分钟诊断 | 评分卡可复算 |
| 案例 |  | 脱敏报告 |
| 交付物 | 诊断报告、评测报告、验收清单 | 可查看样例 |
| 边界 | 达不到就写"先别做" | 报告第 1 页结论 |

> 没有真实案例时写"方法可验"，不编案例。编一次，后面全废。
