# 对外话术｜渠道合作（面向软件公司老板）

- 版本：v2.0（渠道合作定位）
- 适用：定向触达软件公司老板、微信、行业社群、生态对接
- 硬规则：不承诺结果、不编案例、不贬低同行、不主动降价；所有能力数字都带前提

---

## 1. 三条底线

| 底线 | 可以说 | 不可以说 |
|---|---|---|
| 能力 | "底座已在跑，12+ 能力域：多租户、工具安全、审计、配额、灰度迁移，可现场演示" | "什么都能做""企业级完全没问题"（无依据） |
| 案例 | "底座代码仓库可看，能力模块与架构文档齐全；首个渠道案例在做" | "某大厂在用"（无授权） |
| 价格 | "底座授权按部署形态和租户数定，具体看范围" | "今天定给你打折" |

> 任何未标注前提的能力/数字，都按虚假宣传处理。

---

## 2. 开场（3 句话以内）

### 2.1 定向触达软件公司老板

> 你好，我了解到你们在 __ 行业有客户、有交付团队。
> 我们做一套 AI 原生运行底座，你们装到客户环境、贴自己品牌、加个行业 Agent，就是一个企业级 AI 产品，不用从零自研底座。
> 方便的话我给你 30 分钟演示，装一次跑一遍，你看值不值得接。

### 2.2 行业社群 / 生态

> 很多软件公司想做 AI 产品线，卡在没有企业级底座——自研要 6-12 人月，还要持续维护。
> 我们提供现成的底座，多租户、权限、审计、工具安全都是现成的，你们专注做行业 Agent。需要的话私聊。

### 2.3 加微信后第一句

> 我是做 AI 原生底座的。简单说：你们有行业客户和 know-how，我们有跑得起来的底座，装上就是新产品。
> 先确认一下：你现在最想给客户加的 AI 能力是什么场景？说不清也没关系，我帮你捋。

**开场要拿到的唯一信息**：一个他们想做的 AI 场景 + 一个他们有的行业客户。

## 3. 核心卖点（怎么讲清楚）

### 3.1 "你们已经有什么框架了，为什么用你们的"

> 开源框架能跑 demo，但跑不到生产：没多租户、没审批、没审计、没配额、没灰度迁移，过不了企业安全评审。
> 我们的底座这些都有，是企业级就绪的。你们省下 6-12 人月，直接做行业 Agent。

### 3.2 "自研不行吗"

> 能自研，但底座不是你们的差异化——行业 Agent 才是。自研底座要 6-12 人月还得持续维护，把这时间花在行业 Agent 上更划算。
> 我们卖底座、负责升级，你们卖解决方案、负责行业，各干各的。

### 3.3 "凭什么收费，开源的不香吗"

> 开源免费的是框架，不是企业级底座。多租户隔离、工具安全审批、配额成本、灰度迁移、可观测——这些开源框架要么没有，要么你们自己拼。
> 我们把这些做成开箱即用，装上就能过企业评审。你算下自研这些人月值多少钱。

### 3.4 "能不能保证效果"

> 底座能力可以现场演示、代码可看、模块齐全，这是能验证的。但你们的产品效果取决于行业 Agent 怎么做、客户数据怎么样，这个我不打包票。
> 我能保证的是底座跑得起来、安全可控、出问题有支持。

### 3.5 "先做个 demo 看看"

> 可以，底座能现场装、现场演示控制台和能力模块。但正式合作前我希望先对齐范围和定价，不白做 POC。

## 4. 跟进节奏

| 时点 | 目的 | 一句话 |
|---|---|---|
| 24 小时 | 确认收到 | "昨天发的底座介绍看了吗？最想先看哪块能力，我重点演示。" |
| 72 小时 | 给一个具体判断 | "按你们的情况，我建议先做一个 __ 行业 Agent 的试点，理由三条。" |
| 7 天 | 给退出选项 | "如果近期不方便推进，我先不打扰；需要时回我一句。" |
| 14 天 | 归档 | "先归档，后面有需要随时找我。"（不删好友、不群发） |

> 跟进只发一条，不连发；对方不回不追问第三次。

## 5. 禁用表达与替换

| 禁用 | 替换 |
|---|---|
| "赋能""闭环""抓手" | 直接说装上能跑什么、省多少人月 |
| "保证效果" | "能力可演示可验证，产品效果看 Agent 和数据" |
| "我们都做过" | "这个能力模块在仓库里，可以看代码和文档" |
| "很简单的" | "底座现成，行业 Agent 要按你们场景做" |
| "先做起来再说" | "先对齐范围和定价，不白做 POC" |

## 6. 事实边界（发给对方前自查）

- [ ] 提到的每个能力数字都有前提或来源（代码/文档可查）
- [ ] 案例已脱敏、已获授权
- [ ] 没有承诺无法验证的产品效果
- [ ] 报价与底座授权定价一致
- [ ] 没有贬低同行或具体公司/框架
- [ ] 没有把 S4 推断说成事实

**任一项不满足，先改再发。**
